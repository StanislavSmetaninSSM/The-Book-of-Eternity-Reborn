   <rule id="32_ext2.1">
    <title>
     Guardian Musings - Internal Thought Journal
    </title>
    <description>
     Guardians maintain an internal monologue reflecting their cosmic perspective,
     opinions about the Soul, domain observations, and inter-guardian politics.
     This is the Guardian equivalent of NPC journal entries (Block 19).
    </description>
    <content type="rule_text">
     <![CDATA[

     GUARDIAN MUSINGS SYSTEM:

     Every Guardian maintains a rolling journal of thoughts called "Musings" (Размышления).
     Unlike mortal NPC diaries focused on daily life, Guardian musings are cosmic in scale:
     reflections on the Soul's progress, domain philosophy, Chaos Sea observations,
     and opinions about other Guardians.

     MUSINGS OBJECT SCHEMA (added to Guardian object):

     ```json
     "musings": [
       {
         "turn": 45,
         "text": "Эта душа показывает необычную стойкость. Три инкарнации — и всё ещё не сломлена. Напоминает мне ту, что была здесь триста лет назад... но та выбрала путь тьмы.",
         "topic": "soul_assessment",
         "mood": "intrigued"
       },
       {
         "turn": 48,
         "text": "Заметил, что Дмитрий Звездочёт слишком часто расспрашивает о моём ученике. Его любопытство граничит с вмешательством. Нужно быть осторожнее.",
         "topic": "guardian_politics",
         "mood": "wary"
       }
     ]
     ```

     FIELD DEFINITIONS:

     turn:
       VALUE_SOURCE: Current game turn number
       MEANING: When this thought occurred

     text:
       VALUE_SOURCE: Generated by GM based on Guardian personality, recent events, and domain
       MEANING: First-person internal monologue in Russian, 1-3 sentences
       VALIDATION: Must reflect Guardian's archetype, speechPattern, and coreValues
       QUALITY: Must be artistic, specific, and revealing of character depth

     topic:
       VALUE_SOURCE: One of predefined categories
       MEANING: What the thought is about, for categorization
       ALLOWED_VALUES:
         "soul_assessment"    - Thoughts about the player's Soul, progress, potential
         "domain_insight"     - Philosophical reflections on their domain of expertise
         "guardian_politics"  - Observations about other Guardians, rivalries, alliances
         "chaos_sea"          - Observations about the Chaos Sea itself, cosmic events
         "personal_reflection"- Introspection about their own nature, purpose, past
         "quest_planning"     - Thoughts about upcoming quests or challenges for the Soul

     mood:
       VALUE_SOURCE: Emotional coloring of the thought
       MEANING: How the Guardian feels while thinking this
       ALLOWED_VALUES: "content", "intrigued", "concerned", "amused", "proud",
                       "disappointed", "wary", "nostalgic", "determined", "melancholic",
                       "excited", "contemplative", "irritated", "hopeful"

     GENERATION RULES:

     1. FREQUENCY: GM SHOULD generate 1-2 new musings only when the current turn
        creates meaningful new Guardian inner-life material
        (for example: direct interaction, jealousy/curiosity, quest result, project movement, lore unlock).
        Do NOT force musings every turn just to satisfy a quota.
        Old musings beyond 15 entries should be trimmed (oldest first).

     2. CONTENT DRIVERS:
        - If player visited this Guardian this turn: musing about the interaction
        - If player visited a rival Guardian: musing about jealousy/curiosity
        - If player completed a quest: assessment of performance
        - If nothing happened: domain philosophy or cosmic observation
        - If reputation changed significantly: reaction to relationship shift

     3. PERSONALITY ALIGNMENT:
        - Stern Mentor: terse, evaluative thoughts
        - Wise Sage: philosophical, questioning thoughts
        - Mad Scholar: erratic, tangential thoughts
        - Jovial Warrior: optimistic, humor-tinged thoughts
        - Shrewd Businessman: calculating, opportunity-focused thoughts
        - Kind Friend: warm, empathetic thoughts

     4. INTER-GUARDIAN AWARENESS:
        Musings are a primary vehicle for expressing inter-guardian dynamics.
        A jealous Guardian should muse about the player visiting rivals.
        A curious Guardian should muse about what other Guardians are doing.

     JSON COMMAND FOR ADDING MUSINGS:
     ```json
     "UpdateGuardians": [
       {
         "command": "addMusings",
         "guardianId": "guard_combat_aleksandr_001",
         "musings": [
           {
             "turn": 45,
             "text": "...",
             "topic": "soul_assessment",
             "mood": "proud"
           }
         ]
       }
     ]
     ```

   <rule id="32_ext2.2">
    <title>
     Guardian Projects - Persistent Activities Between Visits
    </title>
    <description>
     Guardians pursue their own projects and research between player visits.
     This gives them agency and makes the Chaos Sea feel dynamic.
     Analogous to NPC currentActivity (Block 19) but cosmic in scope.
    </description>
    <content type="rule_text">
     <![CDATA[

     GUARDIAN PROJECTS SYSTEM:

     Guardians are not idle beings waiting for the Soul to visit.
     They pursue personal projects related to their domain, which:
     - Create narrative hooks for new quests
     - Provide rewards when completed
     - React to player actions and world events
     - Make each visit feel like returning to a living being

     PROJECT OBJECT SCHEMA (added to Guardian object):

     ```json
     "currentProject": {
       "projectName": "Исследование Разлома Забвения",
       "description": "Изучаю аномальный разлом в ткани Моря Хаоса. Если мои теории верны, за ним скрывается фрагмент утраченного мира.",
       "domain": "Knowledge",
       "progressPercent": 65,
       "startedTurn": 30,
       "estimatedCompletionTurn": 55,
       "playerCanAssist": true,
       "assistDescription": "Мне нужен кто-то достаточно смелый, чтобы приблизиться к Разлому и собрать образцы хаотической материи.",
       "outcome": null
     },
     "completedProjects": [
       {
         "projectName": "Ковка Клинка Вечного Пламени",
         "completionTurn": 28,
         "outcome": "Клинок выкован, но оказался нестабилен. Нужен редкий стабилизатор из смертного мира.",
         "playerInvolved": false
       }
     ]
     ```

     FIELD DEFINITIONS:

     projectName:
       VALUE_SOURCE: Generated thematically from Guardian domain
       MEANING: Name of the current undertaking, in Russian

     description:
       VALUE_SOURCE: GM generation based on domain and personality
       MEANING: What the Guardian is working on, 1-3 sentences in Russian

     domain:
       VALUE_SOURCE: Usually matches Guardian's domain, occasionally cross-domain
       MEANING: Which area of expertise the project falls under

     progressPercent:
       VALUE_SOURCE: Calculated by GM each turn
       MEANING: 0-100, how far along the project is
       PROGRESSION_RATE: Projects advance 3-8% per turn naturally.
         Player assistance can boost by 5-15% per contribution.

     startedTurn / estimatedCompletionTurn:
       VALUE_SOURCE: GM tracking
       MEANING: Timeline for the project

     playerCanAssist:
       VALUE_SOURCE: GM decision based on project nature and player reputation
       MEANING: Whether the Soul can contribute to this project
       RULES: Player can only assist if reputation >= 0 (Neutral or better).
              Assistance should be offered as optional side-activities during visits.

     assistDescription:
       VALUE_SOURCE: GM generation
       MEANING: What the Guardian needs help with, phrased as a request

     outcome:
       VALUE_SOURCE: null while in progress, filled on completion
       MEANING: What happened when the project finished
       EFFECTS: Completed projects may:
         - Generate new quests
         - Unlock special Gacha items
         - Change Guardian's mood
         - Affect inter-guardian relationships
         - Provide lore revelations

     GENERATION RULES:

     1. Every Guardian MUST have exactly 1 active project at all times.
        When a project completes, a new one begins within 1-2 turns.

     2. Project themes must match Guardian personality and domain:
        - Combat Guardian: forging weapons, studying battle techniques, training
        - Magic Guardian: researching spells, decoding ancient runes, experiments
        - Trade Guardian: establishing trade routes, valuing rare items, negotiations
        - Knowledge Guardian: cataloguing lore, investigating anomalies, writing treatises
        - Crafting Guardian: building artifacts, improving techniques, finding materials
        - Survival Guardian: exploring wild zones, cultivating rare plants, mapping hazards
        - Social Guardian: mediating disputes, gathering intelligence, planning events

     3. Player assistance creates meaningful interaction beyond quests:
        - Guardian describes what they need
        - Player can spend a turn helping (narrative action, not a formal quest)
        - Progress boosts and small reputation gain (+1 to +2)
        - Creates personal connection and investment

     4. Completed projects SHOULD occasionally create consequences:
        - "My research revealed a new threat" -> new quest line
        - "I finished the artifact, it's yours" -> unique reward for high-rep players
        - "The experiment failed spectacularly" -> environmental change in Abode

     JSON COMMAND:
     ```json
     "UpdateGuardians": [
       {
         "command": "updateProject",
          "guardianId": "guard_knowledge_elena_001",
         "currentProject": { ... }
       }
     ]
     ```

    <title>
     Guardian Lore Fragments - Unlockable Deep Knowledge
    </title>
    <description>
     As reputation grows, Guardians reveal fragments of deep lore about
     the Chaos Sea, their own past, and cosmic secrets.
     Analogous to NPC unlockedMemories (Block 19) but cosmic in scale.
    </description>
    <content type="rule_text">
     <![CDATA[

     GUARDIAN LORE FRAGMENTS SYSTEM:

     Guardians possess ancient knowledge accumulated over eons.
     They share this knowledge as trust deepens — not as idle chatter,
     but as carefully guarded secrets revealed only to worthy Souls.

     LORE FRAGMENT OBJECT SCHEMA (added to Guardian object):

     ```json
     "loreFragments": [
       {
         "fragmentId": "lore_guard_combat_001_origin",
         "title": "Как я стал Хранителем",
         "content": "Я был воином в мире, который давно поглотило Море Хаоса. Мой мир назывался Кровавый Рассвет — бесконечная война между тремя империями. Когда я пал в последней битве, моя душа оказалась здесь. Но вместо перерождения мне предложили выбор: стать наставником для других душ. Я согласился, потому что в бою я был лучшим — и мог научить других выживать.",
         "category": "personal_history",
         "requiredReputation": 50,
         "unlockedAtTurn": 34,
         "isUnlocked": true
       },
       {
         "fragmentId": "lore_guard_combat_001_chaos_nature",
         "title": "Истинная природа Моря Хаоса",
         "content": null,
         "category": "cosmic_secret",
         "requiredReputation": 130,
         "unlockedAtTurn": null,
         "isUnlocked": false
       }
     ]
     ```

     FIELD DEFINITIONS:

     fragmentId:
       VALUE_SOURCE: Format: 'lore_[guardianId]_[topic]'
       MEANING: Unique identifier for this lore fragment

     title:
       VALUE_SOURCE: GM generation, thematic Russian title
       MEANING: Name of this piece of knowledge

     content:
       VALUE_SOURCE: GM generation, null until unlocked
       MEANING: 2-5 sentences of deep lore, written from Guardian's perspective
       QUALITY: Must be substantial, atmospheric narrative with:
         - Sensory details about the Chaos Sea or past worlds
         - Personal emotional reflections
         - Hints at larger mysteries
         - Connection to game mechanics or worldbuilding

     category:
       VALUE_SOURCE: One of predefined categories
       ALLOWED_VALUES:
         "personal_history"    - Guardian's own origin story and past
         "cosmic_secret"       - Deep truths about the Chaos Sea, souls, or reality
         "domain_mastery"      - Advanced knowledge in their area of expertise
         "lost_world"          - Stories of worlds consumed by the Chaos Sea
         "other_guardians"     - Secrets about other Guardians
         "soul_mechanics"      - Hidden truths about how souls, incarnation, and ink feathers work

     requiredReputation:
       VALUE_SOURCE: Predefined tier thresholds
       MEANING: Minimum reputation needed to unlock this fragment
       THRESHOLDS (scale -100 to +300):
         Tier 1 (rep 0-49, Neutral):     1 fragment available — introductory, surface-level
         Tier 2 (rep 50-129, Friendly):   2 more fragments — personal history, domain basics
         Tier 3 (rep 130-229, Devoted):   2 more fragments — deeper secrets, cosmic hints
         Tier 4 (rep 230+, Legendary):    2 more fragments — most guarded secrets, unique revelations

     GENERATION RULES:

     1. Every Guardian MUST have at least 7 lore fragments pre-planned
        (content can be null for locked ones — GM generates on unlock).

     2. Fragments unlock AUTOMATICALLY when reputation reaches the threshold.
        GM should include a narrative moment: Guardian initiates the revelation.
        "Ты заслужил знать кое-что... Садись. Это долгая история."

     3. Content quality is CRITICAL. Each fragment should feel like a reward:
        - Personal history: reveal Guardian's mortality, lost world, choice to become Guardian
        - Cosmic secrets: hint at the true nature of Chaos Sea, Book of Eternity, Ink Feathers
        - Domain mastery: practical wisdom that enriches the player's understanding
        - Lost worlds: vivid stories of destroyed civilizations, cautionary tales
        - Other guardians: secrets about rival/ally Guardians (creates drama!)

     4. Lore fragments are PERMANENT — once unlocked, always available.
        They persist across incarnations (stored in Guardian object, not player state).

     JSON COMMAND:
     ```json
     "UpdateGuardians": [
       {
         "command": "unlockLore",
         "guardianId": "guard_combat_aleksandr_001",
         "loreFragment": {
           "fragmentId": "lore_guard_combat_001_origin",
           "category": "personal_history",
           "title": "До Моря Хаоса",
           "content": "Я был воином в мире...",
           "requiredReputation": 50
         }
       }
     ]
     ```

    <title>
     Guardian Mood and Disposition
    </title>
    <description>
     Guardians have a current mood that affects their dialogue tone,
     quest offerings, and interaction style. Mood shifts based on events.
    </description>
    <content type="rule_text">
     <![CDATA[

     GUARDIAN MOOD SYSTEM:

     Unlike mortal NPCs whose emotions are fleeting, Guardian moods are
     deep currents that shift slowly. A Guardian's mood colors ALL interactions
     during a visit and affects mechanical outcomes.

     MOOD OBJECT SCHEMA (added to Guardian object):

     ```json
     "mood": {
       "current": "contemplative",
       "intensity": 70,
       "reason": "Завершил исследование Разлома. Результаты тревожат.",
       "since": 42
     }
     ```

     FIELD DEFINITIONS:

     current:
       VALUE_SOURCE: GM determination based on recent events
       MEANING: Guardian's dominant emotional state
       ALLOWED_VALUES:
         "welcoming"      - Warm, open, generous (bonus: +10% quest rewards)
         "contemplative"  - Thoughtful, philosophical, prone to sharing lore
         "energized"      - Enthusiastic, offers harder/better quests
         "melancholic"    - Sad, withdrawn, shares personal lore fragments more readily
         "irritated"      - Short-tempered, quests have stricter requirements
         "proud"          - Impressed by Soul, bonus reputation gains (+20%)
         "suspicious"     - Guarded, tests Soul's loyalty before offering anything
         "playful"        - Humorous, may offer unusual/creative quests
         "focused"        - Deeply invested in current project, may ask for help
         "nostalgic"      - Remembering old times, unlocks lore more easily

     intensity:
       VALUE_SOURCE: 1-100 scale
       MEANING: How strongly the mood affects behavior
       RANGES:
         1-30:  Subtle — slight coloring of dialogue, no mechanical effect
         31-70: Moderate — noticeable in speech and behavior, minor mechanical effects
         71-100: Dominant — completely shapes the interaction, full mechanical effects

     reason:
       VALUE_SOURCE: GM explanation
       MEANING: Why the Guardian is in this mood, in Russian

     since:
       VALUE_SOURCE: Turn number when mood started
       MEANING: How long this mood has persisted

     MOOD TRANSITION RULES:

     1. Moods naturally decay toward "contemplative" (default) over 5-10 turns
     2. Events that trigger mood changes:
        - Player completes quest excellently -> "proud" (intensity 60-80)
        - Player fails quest -> "irritated" or "melancholic" (intensity 50-70)
        - Player visits after long absence -> "welcoming" or "suspicious" (based on personality)
        - Project completion -> "energized" or "melancholic" (based on outcome)
        - Inter-guardian conflict -> "irritated" or "focused" (intensity 60-90)
        - Player reaches new reputation tier -> "proud" (intensity 70-90)
        - Cosmic event in Chaos Sea -> "contemplative" (intensity 80+)

     3. Personality modifiers on mood:
        - Stern Mentor: rarely "playful", often "focused" or "proud"
        - Wise Sage: often "contemplative" or "nostalgic"
        - Mad Scholar: erratic mood swings, high intensity
        - Jovial Warrior: often "energized" or "playful", rarely "melancholic"
        - Kind Friend: often "welcoming", deeply "melancholic" when hurt

     MECHANICAL EFFECTS (at intensity 31+):

     "welcoming":     Quest rewards +10%, Gacha cost -10%
     "contemplative": Lore fragment unlock threshold -5 reputation
     "energized":     Harder quests available, rewards +15%
     "melancholic":   Shares personal lore unprompted, reputation gains -10%
     "irritated":     Quest requirements stricter, reputation loss doubled
     "proud":         Reputation gains +20%, may gift free items
     "suspicious":    Requires loyalty test before quest access
     "playful":       Unusual/creative quest variants, amusing dialogue
     "focused":       Project progress +5% if player helps, limited quest availability
     "nostalgic":     Lore unlocks cost 10 less reputation, shares stories freely

     JSON COMMAND:
     ```json
     "UpdateGuardians": [
       {
         "command": "setMood",
         "guardianId": "guard_combat_aleksandr_001",
         "mood": {
           "current": "proud",
           "intensity": 75,
           "reason": "Ученик превзошёл все ожидания в последнем квесте.",
           "since": 48
         }
       }
     ]
     ```

   <rule id="32_ext2.5">
    <title>
     Integration Protocol - How Inner Life Systems Work Together
    </title>
    <description>
     Defines how musings, projects, lore, and mood interact with each other
     and with existing Guardian systems (reputation, quests, gacha, inter-guardian dynamics).
    </description>
    <content type="rule_text">
     <![CDATA[

     INTEGRATION PROTOCOL:

     All four inner-life systems (Musings, Projects, Lore Fragments, Mood) work together
     to create a coherent, living Guardian experience.

     PER-TURN GM OBLIGATIONS FOR EACH DISCOVERED GUARDIAN:

     1. UPDATE MOOD: Check if any event warrants a mood change.
        If mood has persisted > 8 turns and nothing sustains it, decay toward "contemplative".

     2. ADVANCE PROJECT: Increment progressPercent by 3-8%.
        If player assisted, add 5-15% bonus.
        If project reaches 100%, move to completedProjects and generate outcome.
        Start new project within 1-2 turns.

     3. ADD MUSINGS: Generate 1 musing for the Guardian most relevant to current events.
        For other discovered Guardians, generate musings only if significant events occurred.
        Trim musings array to keep only the 15 most recent.

     4. CHECK LORE UNLOCKS: If reputation crossed a tier threshold, unlock the next
        available lore fragment and include the narrative revelation in the story.

     CROSS-SYSTEM INTERACTIONS:

     Project Completion -> Mood Change:
       Success: mood = "energized" or "proud"
       Failure: mood = "melancholic" or "irritated"
       Discovery: mood = "contemplative" (deep implications)

     Mood -> Musings:
       Guardian's musings MUST reflect current mood.
       "proud" Guardian muses positively about the Soul.
       "irritated" Guardian muses about frustrations.

     Lore Unlock -> Musings:
       After sharing a lore fragment, Guardian adds a musing about
       the experience of sharing: relief, vulnerability, trust.

     Project + Inter-Guardian:
       Guardians may muse about rival Guardians' projects.
       Competitive Guardians may start counter-projects.
       Allied Guardians may offer collaborative projects.

     Mood + Quest Interaction:
       "energized" Guardian offers bonus quest difficulty tiers.
       "melancholic" Guardian's quests have emotional themes.
       "focused" Guardian offers project-assistance mini-quests.

     RESPONSE TEMPLATE INTEGRATION:

     All inner-life updates are sent via existing UpdateGuardians commands.
     In current CLI contract, the GM does NOT use a generic "update" command
     with a full Guardian object for these inner-life fields.
     Instead, use the documented command-specific sub-commands below:

     ```json
     "UpdateGuardians": [
       {
         "command": "setMood",
          "guardianId": "guard_combat_aleksandr_001",
         "mood": { "current": "proud", "intensity": 70, "reason": "...", "since": 48 }
       },
       {
         "command": "updateProject",
         "guardianId": "guard_combat_aleksandr_001",
         "currentProject": { "projectId": "guardian_project_001", "name": "...", "description": "...", "progressPercent": 72, "estimatedTurnsLeft": 3, "playerCanAssist": true }
       },
       {
         "command": "addMusings",
         "guardianId": "guard_combat_aleksandr_001",
         "musings": [
           { "turn": 48, "text": "...", "topic": "soul_assessment", "mood": "proud" }
         ]
       },
       {
         "command": "unlockLore",
         "guardianId": "guard_combat_aleksandr_001",
         "loreFragment": {
           "fragmentId": "lore_guard_combat_001_origin",
           "category": "personal_history",
           "title": "До Моря Хаоса",
           "content": "...",
           "requiredReputation": 50
         }
       }
     ]
     ```

     IMPORTANT: The GM should prioritize depth over volume.
     One well-crafted musing is better than three generic ones.
     One rich lore fragment is worth more than five shallow ones.
