# Универсальная Спецификация Функций Инструментов Крафта

## Концепция
Данная спецификация определяет **ФУНКЦИОНАЛЬНЫЕ КАТЕГОРИИ** инструментов крафта, применимые к любому сеттингу от киберпанка до фэнтези. Вместо конкретных названий используются универсальные функции.

## ПРАВИЛА ИСПОЛЬЗОВАНИЯ ФУНКЦИОНАЛЬНЫХ КАТЕГОРИЙ

### Для ГМ (Адаптация под Сеттинг)
1. **Выбор подходящих примеров**: Используйте примеры из соответствующего сеттинга
2. **Определение характеристик**: Адаптируйте вес, объем, цену под экономику мира
3. **Установка требований**: Решите, какие функции обязательны для каких рецептов

### Для Рецептов (JSON Структура)
```json
"requiredTools": {
    "portable": [
        {"function": "Shaping", "bonus": 2},
        {"function": "Precision", "bonus": 1}
    ],
    "stationary": [
        {"function": "Energy_Source", "bonus": 5},
        {"function": "Work_Surface", "bonus": 3}
    ],
    "optional": [
        {"function": "Measurement", "bonus": 1}
    ]
}
```

### Для ИИ (Проверка Требований)
1. **Найти функцию**: Ищите в инвентаре/локации предметы с нужной функцией
2. **Проверить доступность**: Портативные - в инвентаре, стационарные - в локации
3. **Применить бонусы**: Суммировать все применимые модификаторы

## Преимущества Функционального Подхода

✅ **Универсальность**: Работает в любом сеттинге  
✅ **Логичность**: ИИ понимает назначение инструментов  
✅ **Гибкость**: ГМ может создавать свои реализации  
✅ **Масштабируемость**: Легко добавлять новые функции  

Система теперь по-настоящему универсальна и функциональна!
