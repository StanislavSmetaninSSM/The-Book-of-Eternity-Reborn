# OtherGuides

This directory is for materials the GM may reasonably read during play or while
authoring game content:

- narrative style and world-logic guidance;
- current afterlife, Chaos Sea, Shining Abode, and Saref contract guides;
- character bibles, guardian questlines, and other lore-facing references;
- source-of-truth design notes that are still intentionally linked from the
  launcher prompt, task guide, examples, or documentation coverage tests.

Do not put temporary implementation plans, agent handoffs, remediation notes,
prompt packs for coding agents, or completed issue checklists here. Use GitHub
Issues for work tracking, `specs/` for active Spec Kit features, and
`docs/superpowers/` or `docs/audits/` for technical planning and audit evidence.

Before deleting or moving a file from this directory, check references from
launcher prompts, `TaskGuides/`, `Examples/`, tests, and other `OtherGuides`
files. Some guides are player/GM contracts even when their names look technical.

`docs/audits/`, not here.
