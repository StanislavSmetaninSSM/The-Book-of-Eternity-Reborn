## Goal and boundary

Support one already active, signed rank-III player-soul wound whose single available strain component targets the last direct-root `pressure/setback` exchange. The component has one stack and magnitude1. This first contour requires `before < ordinary < actual < broken`, with actual exactly one step above ordinary. The general rule remains capped at broken, but capped/no-increase contours are not admitted by this design: without actual increasing strain there is no harmful source to carry the current receipt proof. This proposal does not implement the feature, remove the current refusal, change general combat outcome rules, or implement the separately accepted explicit failed-actor and multiple-wound author rules. Those rules were accepted on 2026-11-04; they are not prerequisites for this single unambiguous wound qualification.

The ordinary result is **counterfactual proposed DATA**, not an event claimed to have occurred historically. The owner proves where the input came from, that it is frozen before deriving actual, and that it satisfies the ordinary rules with precisely this one contribution isolated. Hash agreement alone is not that proof. The owner must not infer ordinary by subtraction from actual, resetting to before, or relabeling an already completed source.

Current `AcceptedMechanicsPlanner.SpiritualExistingStrain.cs` supports existing-parent maneuver against guard; its unchanged-strain reconstruction is lawful only for that existing lane. Current `SpiritualStrainPreimageData` versions1/2 stay strict. The existing guard remains for every unsupported combination until this design and its causal oracle are accepted.
