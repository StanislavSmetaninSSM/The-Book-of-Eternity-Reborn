# r64: повторные проверки каталогов внутри допуска

Реализовано для основного кода игры через существующий `DefaultOperationValidationService`.
Один контекст живёт только в пределах одного синхронного `MainAdmission.Validate`.
Он повторно использует только подтверждённый `EntryKind.Directory` между guard,
worker inventory и чтением main-record. Контекст очищается при возврате и ошибке.
Следующий допуск заново проверяет каталоги. Файлы, отсутствие, ссылки/прочие виды,
перечисление namespace, байты/декодирование main-record и native handle/path остаются
свежими. Worker/remote/original-owner и произвольные read/diagnostic callback'и
сохраняют прежний путь, включая callback через контекст потока.

Выигрыш подтверждён, но 100 секунд не получены. Сохранить этот ограниченный кэш
