## Projection and volatile semantics

P32–174 and text/control-tag helpers are already shared and pure with supplied time:
- Narrative only alters a string response for existing escaped/PowerShell/CR line-break rules. Unchanged returns exact input text; malformed JSON caught as JsonException returns unchanged.
- Interface string options always become objects; object options are deep-cloned, text/inputValue line breaks normalized, recognized leading hidden control tag moved from visible text; an existing nonblank inputValue is preserved. Other element types remain for schema validation.
- Useful payload is exact property presence of dialogueOptions or image_prompt, including null. Missing/null/blank-string timestamp triggers UTC fallback. A numeric/object timestamp or nonblank invalid string does NOT trigger fallback; it reaches existing timestamp diagnostics.
- Changed serialization is indented relaxed-escaping JsonObject.ToJsonString with existing property order. Unchanged/malformed text is not reserialized. Existing filesystem write encoding/BOM behavior stays in FileSystemManager; do not replace it with independently encoded projected bytes.
- One pass is observable: for text “[A_ACTION: x] [B_ACTION: y] Choice”, a pass strips the first tag and can leave the second. A second pass changes visible text again while retaining existing inputValue. No “normalize until stable” loop, no blanket rejection of a valid single-pass result.

Use three distinct dispositions:
1. CurrentNoWriteEvaluation: current text needs no projection/fallback and shared semantic evaluation completes on actual bound reads. This is only this family’s present evaluation, not proof of historical first pass. It does not authorize replaying an earlier ambient timestamp parse; without the relevant actual first-pass parse observation it cannot become a history-complete family.
2. RetainedOrdinaryPass: actual ordinary invocation’s complete source observations, ordered issues, projection and returned write facts are retained and matched to present source. Its actual one-pass result need not be globally idempotent.
3. Unavailable(ProjectionRequired / MissingOrdinaryObservation / SourceChanged / SourceFault / InvocationIncomplete). These are admission-availability states, not additions to ordinary ValidationIssue lists.

If fallback is required without genuine ordinary writer observation, do not supply a dummy timestamp and do not call UtcNow in HOT. The existing wrapper remains the sampler and writer at its existing position. If a projection can be calculated without time, that detached proposed image is still not an observed write.

Retain the actual input and returned parse diagnostic/disposition when used as historical hot evidence. Do not secretly reparse later under different ambient settings and call it the old observation.
