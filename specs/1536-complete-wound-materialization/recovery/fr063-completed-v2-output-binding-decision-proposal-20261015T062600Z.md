## A — immutable output basis inside the existing joint marker (recommended)

Have the real joint owner capture the authenticated local wound reference and the
exact complete narrative_response.json byte image after permitted correction and
normalization, before the common Take. Preserve the accepted pre-common correction
timestamp exception; this proposal makes a new explicit post-common byte policy.
Include
that closed, versioned output basis in the joint common seal and existing marker.
The completed-v2 reader may expose it only after the unchanged real original,
generation, receipt-to-CREATE-to-canonical union and progression proofs succeed.
Use the full accepted byte image to reject current output changes, including
timestamp/format-only changes; no timestamp field is silently excluded. The normal
presentation path still parses and binds the accepted scene to the canonical wound.
An absent consumed draft is legal; any present draft must match its accepted full
fingerprint. Before and after asynchronous output reads, revalidate the current
complete proof. Terminal cleanup still removes the existing marker; old v1 callers
retain their current contract.

No new path, write/delete/rollback member or publication is introduced. No live draft
is recreated. Parsed marker hashes never mint authority. The change is a closed
joint-marker/proof extension, with affected private documentation and guards updated
under the approved design. Risk: larger marker and stricter byte equality; the owner
must prove the captured image is the validated scene, rather than mutable input
reread after Take. Existing narrative line-break normalization must occur before
sealing, or the design must explicitly preserve its legal behavior without a
post-seal writer that falsely invalidates exact binding. The schema must be decided explicitly, without a compatibility
fallback for obsolete joint-v2 development artifacts.

## B — persist output basis in typed acquisition receipt/history

Extend the client-owned typed receipt/history contract to retain the full local
reference and accepted scene basis, then authenticate it through the existing
receipt/CREATE source reconstruction. Risk: changes shared producers, parsers,
history seals and current fixtures; substantially broader than the joint consumer
defect. It still requires strict original/G/full-union/progression checks.

## Required verification after a decision

Use test-first independent SOURCE/FIXTURE/SELECTION gates, fresh BOTH preparation,
exact discovery/catalog and bounded Late2 before later finite stages. Cover absent
draft positive; exact/changed/malformed/foreign present draft; unchanged acquisition
substring with changed surrounding scene; missing/wrong local reference; receipt,
CREATE, severity/event/source mismatch; original/G/marker/footprint tamper; unapplied
and applied cold continuation; stale post-cleanup evidence. Refusals retain committed
mechanics, original/Ready/backups and cause no second mechanics/progression/story.
