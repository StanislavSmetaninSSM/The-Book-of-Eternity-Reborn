## Threat model and correction of the prior criterion

Constitution124–131 and #1553 FR001/004–006/009 define trusted local single-player storage: deliberate closed-save edits are allowed, concurrent external editing is unsupported, exact bytes/absence and crash recovery matter, and protection from the computer owner is not required. Generation, schema, path confinement, accepted-turn consistency and once-only publication still apply.

The earlier requirement to reject *arbitrary NI substitution after an owner coherently rewrites every applicable local hash, operation record and current state* was stronger than this model. Do not add an unforgeable receipt, secret signing authority or independent security anchor to satisfy it. Preserve the old reports as historical findings; supersede that criterion explicitly. A digest is a consistency link, not proof against the local owner. Current-source facts remain true: child1 has no I data, and cold cannot reconstruct the live taken receipt. The correction removes an unnecessary anti-owner requirement; it does not claim those missing fields already exist.

Required refusals remain concrete: malformed/duplicate/unknown fields, unsupported version, noncanonical encoded bytes, incomplete/error-bearing result, wrong generation/frame/request/turn/repair operation, partial copied NI data, stale/cross-operation child/parent links, differing current I presence/bytes, invalid existing original/history/resource/wound/progression proof, unresolved or conflicting journal, and uncertain publication. Coherently rebuilding a whole valid closed-game state is outside the protection claim. Controlled partial substitutions must test the actual crosslinks they violate; do not silently classify all local-hash recomputation as hostile-owner security.

Keep the parent `schemaVersion=2`; use a strict discriminated child `outputBinding.version`:

The child fingerprint covers all fields, using the existing canonical fingerprint writer with an explicit versioned domain. There is no new GUID, publication timestamp or transaction ID. Existing journal transaction IDs are allocated after marker construction and must not be invented/copied into this record.

Parent `niPublication` is closed `{version:1, outputBasisFingerprint:string, commonAuthorityFingerprint:string, inputFingerprint:string, preparedPlanFingerprint:string, fingerprint:string}`. All fingerprint types use the existing authority-fingerprint convention. Its fingerprint is over the other fields plus the existing parent generation/session/request/snapshot/turn/receipt/operation coordinates using a fixed domain. `outputBasisFingerprint` is recomputed from child2; `inputFingerprint` equals the existing parent inputFingerprint. The other values are copied only from the SAME actual taken common candidate. This is a frozen provenance/consistency projection of the actual publication, not a second take receipt.

**No cycle:** returnedInterface/child basis contains no parent input/prepared/niPublication fingerprint. Child → common-authority fingerprint → planning/prepared fingerprints are computed first; only after actual take does marker construction project those values into niPublication; the parent hash is last. Live creation/readback must compare every projected value with that exact receipt/candidate. Cold validates this recorded projection and all current crosslinks under the trusted-local model; it does not recreate the consumed cache, recompute a new common plan or claim an independently unforgeable live-take proof.
