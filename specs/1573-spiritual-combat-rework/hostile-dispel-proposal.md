# Враждебное рассеивание положительных эффектов

2026-11-02, T144, [#1573](https://github.com/StanislavSmetaninSSM/The-Book-of-Eternity-Reborn/issues/1573).
**Принято автором в T145 (2026-11-02), не реализовано.** T143 очищение принято.
Новый обсуждаемый блок — положительные усиления; принятие рассеивания не
утверждает заранее их числа и не снимает production gate.
[Spec](spec.md), [plan](plan.md), [tasks](tasks.md), [review](review.md).

## 1. Что действительно существует и что предлагается

[Смертный пример](../../Examples/E_CLI_Effect_Materialization.txt#L653)
рассеивает боевое сосредоточение: точный эффект, цель и категория
mental_disruption. [Контракт команды](../1535-complete-effect-materialization/contracts/effect-command-and-envelope.md#L65)
разрешает снятие одного active/suspended экземпляра только подходящим способом;
он не устанавливает цену или бросок. [Общий контракт](../../OtherGuides/Effect_Materialization_Contract.md#L273)
сохраняет identity/stacking/lifetime/source authority, а не даёт ГМ удалять
содержимое карточек по имени. Ни один из этих источников не задаёт универсальное
враждебное рассеивание за8P или12P: ниже это новая игровая калибровка.

Выбор: отдельная система ударов/повреждения щита либо общий принцип снятия
эффекта с [очищением](cleansing-proposal.md). Рекомендуется второй: первая
система уже существует как атака по барьеру, а рассеивание даёт другой способ
потратить Main, не нанося этим действием урон. Цены/силовые ориентиры берём
симметричными очищению, без дополнительной надбавки только за враждебность.
Получатель при этом может законно защищаться. Полный баланс не доказан.

## 2. Допустимые цели

Одно обычное рассеивание нацелено на один конкретный обнаруженный положительный
эффект у одного доступного противника. Способ искусства и разрешённая категория
снятия эффекта должны совпасть. Примеры:

- временное усиление характеристики/проверки/урона;
- созданный искусством личный барьер;
- временная прибавка сопротивления либо защитный порог;
- самостоятельный продолжающийся поток периодического лечения;
- временный оберег или иное положительное плетение с разрешённым снятием.

Каждый вид искусства определяет свой способ/область. Слово «рассеивание»
не открывает все эти возможности сразу; волевой разрыв плетения не равен
разрушению материальной брони. Самостоятельный scarlet_flame не подменяется
fire, категории снятия не выводятся из художественного сходства названий.
Свободное действие без карточки возможно по общим правилам выполнимости,
с сопоставимыми расходами/проверкой; оно не получает бесплатно все свойства
освоенного искусства. Опорные волевые щиты T141 предлагается сделать
снимаемыми подходящим рассеиванием плетений, а не по умолчанию неснимаемыми.

Не являются обычными целями:

- постоянная базовая характеристика, ранг, выученное искусство, природа души;
- сама экипированная реликвия и её постоянное свойство; Маска не теряется;
- вся Обитель/домен/фракционная власть/система клятв;
- мгновенное лечение, уже завершённое усиленное действие или прошедший тик;
- скрытый неизвестный эффект без предусмотренного обнаружения/диагностики;
- специальные сюжетные или защищённые состояния, не допускающие выбранного
  способа снятия. Их условия заданы заранее, не после броска игрока.

Постоянный срок сам по себе не делает отдельный active effect ни неснимаемым,
ни обычной дешёвой целью: действует его конкретный способ разрешения. Временный
эффект, созданный предметом, может быть снят, если допускает это, но предмет
и его постоянные свойства остаются. Подавление постоянного свойства/ауры,
кража баффа, передача его себе или запрет повторного наложения — отдельные
профили, не скрытые преимущества этого рассеивания.

### Экземпляры, стеки и составные эффекты

Как в T143, обычный стековый экземпляр снимается целиком с его стеками.
Независимые экземпляры/источники — отдельные цели. Все компоненты одного
экземпляра прекращаются вместе: нельзя выбрать только приятный врагу компонент
смешанного баффа/дебаффа, оставив его цену/недостаток. Такой смешанный пакет
можно снять целиком лишь при разрешённой категории снятия целого; игрок
получает понятный прогноз всех известных прекращаемых частей. Частичное
редактирование компонентов требует иного явного профиля. ГМ не перепаковывает
состояния перед рассеиванием ради более выгодной единицы цены.

Эффекты на разных душах всегда имеют личные экземпляры. Снятие одного
получателя не выключает всё групповое благословение или источник ауры.
Источник может позднее снова наложить эффект только по своим обычным правилам,
оплаченному применению или разрешённому событию; не бесплатно от чтения профиля.

## 3. Действие, цена и проверка

```text
P = 1 + D_рассеивающего/50
G(m) = (1 + 0.04m)/1.04
```

| Режим при m1 | Действие | Бонус техники | ДЭ |
|---|---|---:|---:|
|Обычное точечное рассеивание|Main|+5|8P|
|Усиленное точечное рассеивание|Main|+10|12P|

K растёт как5G(m) либо10G(m). Цены не растут с мастерством. Новые режимы,
число целей и способы снятия не открываются автоматически. Это отдельная
враждебная возможность: владение обычным очищением не даёт её само по себе.

```text
Рассеивающий: d20 + M_Воли_сейчас + K
Защита плетения: d20 + S_эффекта + явно применимые модификаторы этой проверки
```

S зафиксирована при создании эффекта по той же схеме T143:
`M_заданной характеристики источника при создании + B_устойчивости`.
Для опорных волевых щитов T141 предлагаем S=M Воли создателя, B=0,
если источник не имеет отдельной устойчивости. Величина запаса барьера,
стоимость его создания и исходный d20 в S не входят. Рост mastery, который
усиливает только запас щита, не усиливает автоматически все его остальные
свойства; устойчивость можно развивать отдельным явно описанным компонентом.
У эффекта среды без души S должна быть задана источником заранее.

Это **единственная обычная встречная проверка** данного снятия. Не добавлять
сначала текущую Волю получателя, потом S создателя и затем ещё status-save.
Получатель слабее создателя не обнуляет прочность подаренного ему плетения;
изменение характеристик создателя позднее не усиливает старый эффект.
S остаётся у эффекта и когда создатель далеко или уже не участвует в бою.
Потеря источника прекращает плетение только по его собственному lifetime.

Новые эталоны волевые; искусство иного способа может явно задавать иной
подходящий contest. Общие исходы/Благоволение/модификаторы проверок сохраняются.
Любой успешный исход, включая частичный, полностью прекращает выбранный
допустимый экземпляр. Провал оставляет его. Крит не крадёт эффект, не добавляет
вторую цель/урон и не запрещает повторное создание. Mastery-награда по исходной
активации/заранее назначенному главному результату, не за каждый компонент.

## 4. Защита получателя

Предлагается явно распространить существующую [активную защиту+5/4P](reactions-and-interruptions-proposal.md#L75)
на попытку укрепить **выбранный свой эффект** перед его рассеиванием.
Это новая оговорённая адаптация к source-strength check, не уже принятая
фраза T143 о помощи согласному союзнику.

Получатель должен заметить попытку, иметь выполнимый способ поддержать
плетение, доступную общую реакцию и достаточно ДЭ. Он до костей платит
4P **своего** развития и добавляет+5 к одной защитной проверке S.
Этот+5 не умножается на P или mastery, не добавляет вторую кость, не меняет
сохранённую S после действия и не увеличивает сам барьер/величину баффа.
Полностью оглушённый или находящийся в HP0 не выполняет активную реакцию;
сама обычная проверка против S сохраняется даже без неё.

Неиспользованная реакция не даёт эту прибавку автоматически. При нескольких
проверках выбирается одна; одна общая реакция и один ответ на цепочку остаются.
Удалённый создатель эффекта не платит/не реагирует за получателя автоматически.
Другой союзник вмешивается лишь подходящим реальным реактивным профилем,
а не суммирует свои Воли с S без отдельного основания.

Обычное сопротивление вредным состояниям T142, иммунитет к контролю и
уронные R/порог/барьер не блокируют это снятие сами по себе. Оно не наносит
урон и не накладывает контроль. Специальная устойчивость к рассеиванию должна
быть явно определена и учитывается один раз в назначенном ей месте;
обычная общая защита от состояний не преобразуется в неё постфактум.

Базовое прикрытие не переносит выбранный чужой бафф на прикрывающего:
это не обязательно перехватываемый прямой удар. Контратаки/прочие реакции
доступны только при выполнении собственных условий, а не из одного факта
неудачи рассеивания. Конкретный способ доставки может дать такие условия,
но текущий эталон не создаёт дополнительной бесплатной реакции.

## 5. Что именно прекращается

**Барьер:** удаляется его оставшийся запас. Никакого HP-урона на величину
остатка, возврата ранее поглощённого урона или переноса запаса себе.
[Принятый договор](threshold-and-barrier-proposal.md#L123) сохраняется.
Если один законно снимаемый эффект содержит несколько собственных барьерных
компонентов, заканчиваются его компоненты; чужие экземпляры других источников
остаются. Рассеивание может быть выгоднее пробивания большого запаса ударами,
но стоит Main/ДЭ, требует способа и может не удаться. Это намеренная контригра,
не доказательство полной равноценности способов.

**HoT:** прекращаются будущие тики выбранного экземпляра. Полученное ранее
HP не отнимается; остальные потоки живут по своим принятым правилам семейства.
Это снятие уже действующего эффекта, не возвращение отменённого срыва лечения.

**Бафф сопротивления/порога/характеристики:** удаляется только его вклад.
Остальные источники пересчитываются обычным образом; нельзя занулить всю
защиту цели. Изменение Чуткости влияет на соответствующие текущие проверки,
но [уже построенная очередь](initiative-and-personal-turn-proposal.md#L74)
в середине раунда не перестраивается, следующий раунд учитывает изменения.

**Временный модификатор максимума:** законное прекращение уменьшает максимум
по [существующему договору](reserve-and-harmony-proposal.md#L183).
Абсолютный current сохраняется, если помещается; иначе ограничивается новым
max. Это сверка ресурса, не отдельный урон/похищение/заработок атакующего.
Повторное увеличение max само current не пополняет. Постоянная Собранная воля
Маски этим не становится целью рассеивания.

Снятие не возвращает потраченные Main/реакции/ДЭ и не изменяет прошлые события.
Повторное законное создание баффа разрешено без нового общего cooldown/grace.

## 6. Несколько эффектов/целей и исполнение

Освоенный режим задаёт максимальный охват и допускаемые категории. Базовая
калибровка —8P за каждое обычное либо12P за каждое усиленное снятие при одном
Main на разрешённое применение. По каждому заранее выбранному экземпляру
отдельная проверка/S; получатели применяют собственные допустимые реакции.
Цена за попытки, не только за успехи. Нельзя выбирать новую цель после
неудачи или многократно перебрасывать тот же экземпляр в одной активации.
Смешанная атака «рассеять+ударить» — отдельный оплаченный профиль;
базовое рассеивание не наносит бесплатный B14 или другой урон.

Выбор доступных эффектов, стоимость и допустимость фиксируются до бросков.
Пустой/неверный target или несовместимый способ отклоняются до расхода;
принятая попытка тратит полную цену и Main, даже если проиграла силе защиты.
Обнаружение неизвестных баффов требует реального восприятия/диагностики;
доступность технической карточки агенту не даёт герою всеведение.
Повтор/reload сохраняет результат/расход, а не бросает и не платит заново.
Обычный Main-режим не становится мгновенной реакцией просто из-за команды.

## 7. Численные примеры

D50 даёт P2: обычное16ДЭ, усиленное24ДЭ; два обычных экземпляра32ДЭ.
При D210 цены41.6/62.4ДЭ; две усиленные попытки124.8ДЭ. Реакция получателя
с D50 стоит8ДЭ, с D210 —20.8ДЭ, вне зависимости от D атакующего.
При m1/10/25 обычный K=5/6.7308/9.6154, усиленный10/13.4615/19.2308.

**Одна проверка.** При D50/Воле22 M=62. Щит создан с S62. У атакующего
обычный режим даёт M62+5. Броски10 против12:77−74=+3 — частичный успех,
щит снимается. Если получатель заранее применил подходящую реакцию+5,
получится77−79=−2 — провал. Усиленное рассеивание при тех же костях даёт
82−79=+3 — успешное снятие. Это фиксированные некритические исходы,
не вероятность победы и не запрет природных критов по принятому договору.

**Барьер.** У цели осталось73.4 запаса выбранного щита и есть другой щит20.
Успешное снятие первого убирает73.4, второй сохраняет20; HP не изменяется.

**Лечение.** Из трёх тиков по20 уже прошёл один. Успешное снятие этого HoT
отменяет будущие два тика по20, но не отнимает уже полученные20HP.
Фактическая полезная прибавка каждого тика подчинялась своим прежним модификаторам.

**Максимум.** У снимаемого временного баффа+20maxDE: состояние115/120 после
его окончания становится100/100;80/120 становится80/100. Повторное получение
того же max даёт соответственно100/120 либо80/120 без refill. Это пример
временного эффекта, не разрешение снять постоянный бонус Маски.

## 8. Границы проверки и внедрения

Новые цены/адаптация реакции требуют согласования. Арифметика не доказывает
баланс высокой Гармонии/численности/экзотических защищённых эффектов.
Код/Rules/материализация не меняются. Исполнимому плану нужны S/категория,
exact effect/target, реактивное решение до костей, source authority,
переоценка зависимых ресурсов/проекций, идентичность двух UI и accepted replay.
Нельзя превращать старый side carrier в личный buff без миграции модели.

Нового кэша/дорогой runtime работы здесь нет. При внедрении стабильные
определения и проекции читаются через существующий сервис по identity/revision;
после снятия инвалидируются зависимые данные. Текущие цель/ресурс/разрешение
и наличие эффекта проверяются свежими, без повторного чтения всех файлов
для каждой составляющей одной проверки.
