Proposal: use a monotonically increasing prompt sequence scoped to the **current input binding**, encoded into the operation identity and included in delivery/query frames. Dispose settled CTS/remove completed task references only after original work settles; unresolved tasks remain in stop/drain ownership and block unsafe replacement. Add `DaemonRestart_SameLiveBindingQueriesOriginalSequence` and `ChangedBinding_DoesNotMintLostDispatchAuthority` tests.
