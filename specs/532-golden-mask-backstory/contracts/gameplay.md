# Предлагаемый пользовательский и GM-контракт

Проект 2026-10-26; D1–D4 и точная версия spec требуют рассмотрения автора.
Ни одна из новых команд/структур ниже пока не реализована.

## Воспоминания

| Действие | Семантика |
|---|---|
| `/воспоминания` | Read-only список открытых личных сцен без private definitions |
| `/воспоминания начать <id>` | Mutating command; точная доступная сцена, её новая попытка/запуск |
| `/воспоминания продолжить <id>` | Mutating command; существующая paused-попытка после fresh checks |
| `/воспоминания покинуть` | Mutating command; pause текущей попытки, без награды/потери принятых узлов |
| Обычное действие внутри сцены | GM turn с attached exact definition, ролью и source; advancement только этой сцены |

Команды представлены теми же действиями в браузере. Чтение меню не запускает
ход/сцену. Не менять смысл существующих singular aliases незаметно: их
read-only dossier может показывать текущий envelope, запуск идёт через новый
явный mutating route. Если будет выбран единый старт и для q4, он получает
тот же eligibility gate и отдельные тесты, а не переименование старого reader.

До раскрытия: нейтральный заголовок/карточки. После: разрешённая история Маски.
Скрытые определения не передаются клиенту с CSS hidden: проектируется только
разрешённое содержание. Незнакомый/недоступный ID не выдаёт private описание.
Текущий пользовательский облик не заменяется портретом «истинного лица».

В активной сцене UI явно показывает временную роль и возможность выйти.
Новая инкарнация, обычная внешняя покупка/переход, другой scene owner запрещены
до выхода. Existing active conflict/prepared incarnation/pending incompatible
mutation запрещают запуск; это проверяется в общем сервисе, не только кнопкой.
После паузы обычная игра доступна, resume повторно проверяет контекст.

## GM и принятие хода

GM с начала игры знает compact story truth, но персонажи/игрок узнают её
по своим событиям. Полный exact memory package прикладывается для активной
сцены. Catalogue missing/mismatch — ошибка определения, не просьба GM выдумать.

GM предлагает narrative + ограниченные node transitions. Harness проверяет:
source/definition/attempt, прежние узлы, допустимый переход, фиксированные
исторические события и критерии завершения. Semantics свободного текста не
«доказываются» одним Boolean: проверяемые claims/узлы сопоставляются с точным
сценарием; литературная правдоподобность дополнительно проверяется примерами
и содержательным ревью. Не обещать формального распознавания всей прозы.

При личном closure harness определяет единственную разрешённую награду
из каталога, строит profile+story after-images и включает их в существующий
accepted turn. Ошибка любого участника отменяет весь эффект. Награда становится
доступна следующему допустимому действию по принятому pre-turn состоянию.
Меню, обычная нормализация и retry не предоставляют самостоятельного grant.
Guardian q4 proof/revelation/advantage остаются в собственной ветке проверки.

## Посещение Нового Порядка (вариант realm)

Предлагаемые `/новый_порядок войти` и `/новый_порядок вернуться` — узкие
client-owned переходы с fresh owner/realm/location checks. Точные алиасы
и условия привязываются к D4, а не внедряются по этому черновику.
Первый маршрут: из раскрытого сюжетного входа Обители с сохранённым return context.

Вход не выдаёт членство, клятву, награду, раскрытие личности или победу.
Возврат не увеличивает currentIncarnation и не сбрасывает Enlightenment,
Radiance, soulProgression, inventory или историю. Договорные запреты связанной
души учитываются отдельно; гостевой путь не отменяет их.
Один canonical Saref/Wings может иметь проверенное присутствие в новом месте.

Первый trade scope — известные Soul Relics за Ink Feathers. Предложение
содержит ссылки на тот же faction inventory; перед покупкой проверяются
fresh locality, owner, stock, цена, ресурсы и отсутствие duplicate relic.
Переход/финал/смена наличия делает старую карточку недостаточным основанием.

Совместимые первоначальные механики: сюжетные взаимодействия, чтение личной
памяти, утверждённые искусства/духовные конфликты, владение ресурсами, торговля.
Shining-specific врат/инвестиций/gacha/New Cycle там нет без отдельного решения.
Worker repair получает только точные разрешённые корни этого действия;
простое добавление realm не разрешает менять все afterlife roots.

## Обязательные примеры

1. Неизвестная личность: косвенный trace без спойлера и без создания всех акторов.
2. Guardian q4 и личная сцена: разные source, proofs и награды.
3. Личная сцена: start→pause→resume→completion→реальное применение искусства.
4. Rejected completion/recovery/replay: ни половинной, ни двойной выдачи.
5. Первая встреча с Сарефом в обоих порядках раскрытия.
6. Visitor round-trip и stale trade refusal без reset/клятвы/дубликатов акторов.
7. Освобождение убежища: отдельные последствия для населения, сердца и Крыльев.
