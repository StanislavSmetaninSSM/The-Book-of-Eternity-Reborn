# Предлагаемый пользовательский и GM-контракт

Проект 2026-10-26 после уточнения автора: D1 и основной D2 приняты;
детали сценического контекста, D3/D4 и точная версия spec требуют рассмотрения.
Ни одна из новых команд/структур ниже пока не реализована.

Принятый автором 2026-10-27 полный сценарий личной памяти:
[второй эпизод Маски v1](../scenarios/golden-mask-02-summoning.md).
Его исследование, переговоры, локальный обряд, цены и исходы приняты в редакции
`826453cc1867238628690d3abb77bb7b59444d82`. Техническое определение, реализация
и проверка баланса ещё впереди. Награды и общие правила отказа/изоляции сохраняются.

## Воспоминания

| Действие | Семантика |
|---|---|
| `/воспоминания` | Read-only список доступных личных и Guardian-сцен без private definitions |
| `/воспоминания начать <id>` | Mutating command; точная доступная сцена, её новая попытка/запуск |
| `/воспоминания продолжить <id>` | Mutating command; существующая paused-попытка после fresh checks |
| Повторить завершённое воспоминание | Новое прохождение для пропущенных целей; прежние награды и завершение сохраняются |
| `/воспоминания покинуть` | Mutating command; pause текущей попытки, без награды/потери принятых узлов |
| Карта / где я / местные персонажи | Read-only проекция сцены, её временной роли и открытых мест |
| Перейти / осмотреть / поговорить | Адресуемое сценическое действие через общий player action; цель существует и доступна в текущем месте |
| Обычное действие внутри сцены | Memory GM turn с exact definition, исторической ролью владельца памяти и source; изменения внутри сцены |

Команды представлены теми же действиями в браузере. Чтение меню не запускает
ход/сцену. Нынешняя `/воспоминание_начать` ошибочно ведёт в read-only dossier.
Предложение: её start alias явно перевести в тот же mutating launch route,
обновив help, classification, router и обе клиентские проверки; простое
`/воспоминание` оставить досье. Оба источника запускаются общим сервисом,
но Guardian q4 требует свои exact quest prerequisites. Не оставлять ложную
обещающую запуск команду как второй неработающий путь.

До раскрытия: нейтральный заголовок/карточки. После: разрешённая история Маски.
Для личной ветки автор выбрал последовательный доступ: первое успешное
воспоминание любого Хранителя пробуждает маску и открывает первый личный эпизод;
успех эпизода открывает следующий. Дополнительные цели не обязательны, replay
не продвигает цепочку через непройденные сцены и не закрывает прежний доступ.
Первым выбран эпизод «Убежище для потерянных» до призыва Сарефа, вторым — призыв.
Цели и награды обоих приняты; полный второй сценарий v1 также принят,
полный первый проект v2 ещё требует рассмотрения;
оставшийся порядок эпизодов уточняется в D3/D4.
Скрытые определения не передаются клиенту с CSS hidden: проектируется только
разрешённое содержание. Незнакомый/недоступный ID не выдаёт private описание.
Текущий пользовательский облик не заменяется портретом «истинного лица».

В активной сцене UI явно показывает временную роль и возможность выйти.
Новая инкарнация, обычная внешняя покупка/переход, другой scene owner запрещены
до выхода. Existing active conflict/prepared incarnation/pending incompatible
mutation запрещают запуск; это проверяется в общем сервисе, не только кнопкой.
После паузы обычная игра доступна, resume повторно проверяет контекст.

Один active owner и сохраняемые paused sessions: A→pause→B→pause→A не стирает
прогресс A. Карта/досье сами ничего не меняют. Нажатие узла открывает сведения;
отдельное действие «Перейти» проверяет ребро/условие и принимается как действие.
Разговор использует historical local actor, осмотр — exact scene prop/location.
Все три действия проверяют instance/revision/исходное место/generation; устаревшая
кнопка после перемещения или выхода не отправляет ход другому собеседнику.

Свободный текст сохраняется: GM трактует его в пределах definition. Персонажи
доступны там, где находятся в принятом состоянии сцены; предметы и знания прошлого
не дают прав на нынешний инвентарь. Исторические способности ограничены сценой.
Уточнение автора: исторический Маска имеет искусства предшествующих по цепочке
личных воспоминаний на V уровне; в четвёртой памяти Оковы/Исток/Оплот V.
Их уровни/допуски берутся из согласованной исторической роли, не из прокачки
нынешнего героя. Позднейший прогресс не добавляет будущие искусства в раннюю память.
V сохраняются в рамках попытки и не переносятся в постоянный профиль/учёт наград;
боевые цены/ОД/ограничения роли продолжают действовать. Уровень текущего Приговора
и точные параметры исторического профиля ещё требуется задать сценарием.
Fixed событие нельзя отменить, но подход, разговоры и допустимые открытия могут
различаться. Историческое поражение Маски не равно неудаче прохождения памяти.

Принято автором 2026-10-26: каждый ввод сначала проверяется на соответствие
реальности памяти, исторической роли и сценарию. Недопустимый игровой ход
отклоняется целиком с понятной причиной; раскрытие ограничено явно заданной
сценарием подсказкой. Вторая память Маски допускает намёк о выгоде публичной
роли Сарефа и расторжимости договорённости о ролях при её жёстком отрицании
(подробности и границы — в spec.md). Это не раскрывает весь план и не меняет
печать; допустимый торг не отклоняется только за жёсткую формулировку.
При отказе состояние/время/ресурсы
сцены, реакции NPC, цели и награды не меняются. Игрок может повторить ввод
из прежнего состояния или выйти. Служебная запись отказа не становится событием
сцены. Ограничения роли заданы сценарием, а не придумываются GM по ходу разговора.
Допустимая попытка убедить NPC не гарантирует нужного игроку исхода; уместная
импровизация/побочная беседа разрешена. Допуск хода не означает выполнения цели.
Ошибку GM исправляют до принятия; она не даёт штрафа игроку. Смысловая оценка
остаётся задачей GM, клиент обеспечивает структурные проверки и отсутствие
эффектов отказа; формальной гарантии распознавания всей прозы нет.

## GM и принятие хода

GM с начала игры знает compact story truth, но персонажи/игрок узнают её
по своим событиям. Полный exact memory package прикладывается для активной
сцены. Catalogue missing/mismatch — ошибка определения, не просьба GM выдумать.

GM получает scenario/cast с period knowledge, роль и актуальное состояние;
обычные текущие ActorMemory/characteristics/trade/progression reminders не
подмешиваются. Normal и repair маршруты используют один memory contract.
GM предлагает narrative + сценические переходы/разговоры/открытия. Harness проверяет:
source/definition/attempt/state revision, локальность, способности роли,
прежние узлы, действия-доказательства, допустимый переход, fixed events и closure.
Semantics свободного текста не
«доказываются» одним Boolean: проверяемые claims/узлы сопоставляются с точным
сценарием; литературная правдоподобность дополнительно проверяется примерами
и содержательным ревью. Не обещать формального распознавания всей прозы.

При личном closure harness определяет единственную разрешённую награду
из каталога, строит profile+story after-images и включает их в существующий
accepted turn. Ошибка любого участника отменяет весь эффект. Награда становится
доступна следующему допустимому действию по принятому pre-turn состоянию.
Меню, обычная нормализация и retry не предоставляют самостоятельного grant.
Guardian q4 proof/revelation/advantage остаются в собственной ветке проверки.

Принято автором: при повторном прохождении можно получить первую награду за
ранее не выполненную цель. За уже награждённую цель выдача не повторяется;
retry/reload/новая attempt не делают её новой. Основное q4 completion/reward
также не выдаётся заново. Автор утвердил: награды только после успешного
завершения памяти, в том числе при доборе на replay. Прогресс цели внутри
попытки ещё не даёт постоянного повышения. Exact goal-proof уточняется до кода;
для Илариона сценические основания зачёта утверждены в
[сценарии v1](../scenarios/ilarion-memory.md), машинное представление ещё проектируется.

Принято автором: изученное применимое искусство Хранителя у нынешнего игрока
невозможно до успешного завершения именно его воспоминания. Gate проверяется
на всех путях обучения/получения/повышения, включая нынешний learning tier 0;
для Илариона принята шкала 1–5 ниже, остальные уточняются. Исторический владелец памяти
использует сценическую способность без предоставления нынешнему игроку искусства.
Повтор основного завершения не выдаёт начальный уровень заново и не понижает
текущий. Добор целей после обычного обучения разрешён. Gate относится к соответствующим искусствам
Хранителей, не вводит требование памяти для всех остальных духовных искусств.

Принято автором для Илариона: первое успешное завершение даёт уровень 1,
обычное обучение — суммарно до двух повышений, каждая из двух дополнительных
целей — ещё одно повышение однократно. Максимум 5 достижим только с обеими целями.
Награды и обычные повышения учитываются по источнику; нельзя подменять лимит
обучения проверкой «текущий уровень не выше 3»: после двух целей с уровня 3
доступны ещё два обычных повышения. Порядок не меняет итог, replay не сбрасывает
счётчики/выдачи и не понижает уровень. Ресурсная компенсация не вводится.
Принято автором: ранговый допуск един для повышения обучением и наградой.
Заработанная награда при недостаточном ранге сохраняется и применяется при
достижении допуска автоматически, без платы/повтора. Заработанное повышение
фиксируется только при успешном завершении; exact activation contract ещё согласуется. Исключений,
позволяющих обойти ранг порядком обучения/прохождения, нет.

Принято автором 2026-10-27 для собственных искусств Маски: после открытия
соответствующим воспоминанием самостоятельная практика восстанавливает прежнее
мастерство на условиях обучения у учителя, без повышенной цены самообучения.
Коэффициент стоимости принят равным 100% базовой цены: скидки наставника 80%/60%
не применяются, снимается только пятикратная надбавка самообучения.
Базы приняты 2026-10-27: 325 Чернильных Перьев за платный +1 Оков Владыки,
300 за платный +1 Истока Владыки; Искры Света не требуются и не принимаются
как альтернативная оплата. Цена фиксирована независимо от текущего/целевого
уровня и порядка получения наград памяти. Награды памяти этим тарифом не облагаются.
Физический наставник/фиктивный NPC не требуется. Основание льготы — собственное
искусство Маски и подтверждённое открытие через его память, не одно название
или произвольная отметка GM. Общие ранги, реальная оплата и однократный учёт
повышений сохраняются; чужие искусства не получают льготу. Для Оков и Истока
отдельно разрешены два повышения практикой суммарно на каждое искусство,
независимо от порядка получения наград целей.
Практика не заменяет пропущенную цель и не открывает начальный уровень раньше
завершения. Точный контракт допуска/расчёта/публикации требуется в T009/#1566.
Принято автором 2026-10-27 для второй памяти: первое успешное завершение M1–M3
открывает I уровень Истока, O1 «Соглашение без угроз» и O2 «Невредимое воплощение»
дают по одному повышению однократно после успешного завершения. Вместе с двумя
практиками по 300 Перьев (суммарно 600, без Искр) это максимум V; без обеих целей
V недоступен. Награды памяти бесплатны. Общий ранг и сохранение неприменённых
наград действуют как выше; retry/replay не сбрасывают лимиты, не дублируют
награды/оплату и не отзывают полученное. Источники повышений учитываются отдельно
от Оков; исторические уровни/предметы не переносятся. Награды дальнейших
эпизодов этой схемой не назначаются.

Отдельно принято автором 2026-10-27 для третьей памяти: первое успешное
завершение открывает I уровень «Оплота Владыки»; O1 «Никто не остался в стороне»
и O2 «Защита для слабых» дают по одному бесплатному повышению однократно
после успеха. Допускаются две платные практики суммарно на Оплот, по 100%
ещё не выбранной базовой цены; максимум V требует обеих целей и обеих практик.
Учитывать источники отдельно от Оков/Истока, сохранять общий ранг/отложенные
награды и запрет открыть первый уровень практикой. Порядок добора свободный,
replay/retry не дублирует награды и не сбрасывает лимиты. Конкретные I–V и
3 ОД применения приняты автором по редакции `41f734402893766bda79063438f8d3280afde4f0`:
резерв full/partial 1/0, 1/1, 1/1, 2/1, 2/2; с III обычное Преимущество
Оплоту против pressure, без сложения обычных источников. Срок/одноразовость,
нагрузка ран и наказанное восстановление сохраняются. Исполнения эффекта ещё нет.
[Полный сценарий третьей памяти v1](../scenarios/golden-mask-03-last-word.md)
принят автором в редакции `5da0605f116f299b9c0f5f2375b52123eb567f17`:
переговоры/вклады, этапы обряда, сценарные доказательства целей и граница O2
при реальном ослаблении внутренней защиты (без возврата зачёта после исправления).
Его принятие не утверждает exact definition или проверенный игровой баланс.

Для четвёртой памяти автор принял действия/цели M1–M4/O1–O2 из
[spec](../spec.md), редакция `e2486cc1f57f0fc27ca0660b225d5977fd0908ad`:
снятие/заключение смотрителя, победа с доступным пленом, публичный приговор
Сарефа без нового приказа печати и сознательное личное развеивание Маской.
O1 теряется после действительного срыва работы общего узла; O2 требует
достоверного переданного свидетельства. Все четыре сочетания должны сохранять
основной маршрут. Полный сценарий/доказательства не утверждены этим решением.
Отдельным решением по редакции `84f1fda4cf41e99e92b32bf4821c8e2d791fabb9`
приняты Приговор (`pressure`) и его схема наград: I после завершения, по +1 за
O1/O2 и две платные практики суммарно по 100% базовой цены. Источники отдельны,
максимум V требует обеих целей/практик; ранги, отложенные повышения, однократность
и успешное closure сохраняются. Ядро усиливает новое давление при полном успехе
под pre-turn контролем своей стороны, без изменения позиции/оков/терминального
исхода и обхода тактической матрицы. I–V/6→3 ОД приняты по редакции
`14854354cf1a37ede5cfcef59b80f31e28fdc387`: full/partial добавки 1/0, 1/0,
1/1, 1/1, 2/1; с IV обычное Преимущество при том же контроле. Цена практики
и исполняемый контракт эффекта остаются открытыми; игровой баланс не проверен.

Для искусства Илариона приняты пять эффектов и активация за 2 ОД до внешних
модификаторов, без платы за удержание; точная таблица — в разделе spec
«Якорь Невытравленного Имени»: принятые пять уровней и цена.
Она сохраняет один якорь/одну память, согласие чужого владельца, штатные roll
modes и однократную страховку уровня 5 на целое противостояние. Принятие таблицы
не реализует memory-target/consumption consumer: точная привязка источника,
цели, согласия и предотвращения подмены требует завершения D3/#1571 contract.

Trusted pending snapshot выбирает memory mode до запуска GM. Helper и accepted
validation ограничивают разрешённые записи scene state/transcript и точным closure;
изменение настоящего вне этого набора отклоняется с существующим rollback.
Current soul/location/profile, present actor journals/relations и обычные
world/guardian/faction/trade state не становятся writable из-за исторического
сценария. Служебные request/receipt/save/history изменения перечислены отдельно.
Нельзя считать prompt самостоятельной гарантией целостности.

Рекомендуемая политика времени: отдельный scene ordinal; глобальные protocol
номера продолжают расти, но exploration не продвигает настоящее. Уже существующий
pending backlog сохраняется, catch-up за память не создаётся. История сцены
привязана к instance/POV, не дописывается как нынешняя беседа реального NPC.
При завершении возвращается только зарегистрированный итог/знание/награда.

Для всех десяти Guardian q4: POV — сам исторический Хранитель, отдельная
source-specific награда сохраняется. Переработка способностей/узлов обязательна.
Сценическая жертва Илариона или признание Вейры не меняют нынешнюю личность игрока
и не списывают её память; возможная нынешняя рефлексия — отдельное событие.

## Посещение отдельного Нового Порядка

Предлагаемые `/новый_порядок войти` и `/новый_порядок вернуться` — узкие
client-owned переходы с fresh owner/realm/location checks. Точные алиасы
и условия привязываются к D4, а не внедряются по этому черновику.
Первый маршрут: из раскрытого сюжетного входа Обители с сохранённым return context.

Вход не выдаёт членство, клятву, награду, раскрытие личности или победу.
Возврат не увеличивает currentIncarnation и не сбрасывает Enlightenment,
Radiance, soulProgression, inventory или историю. Договорные запреты связанной
души учитываются отдельно; гостевой путь не отменяет их.
Один canonical Saref/Wings может иметь проверенное присутствие в новом месте.

Первый trade scope — известные Soul Relics за Ink Feathers. Предложение
содержит ссылки на тот же faction inventory; перед покупкой проверяются
fresh locality, owner, stock, цена, ресурсы и отсутствие duplicate relic.
Переход/финал/смена наличия делает старую карточку недостаточным основанием.

Совместимые первоначальные механики: сюжетные взаимодействия, чтение личной
памяти, утверждённые искусства/духовные конфликты, владение ресурсами, торговля.
Shining-specific врат/инвестиций/gacha/New Cycle там нет без отдельного решения.
Worker repair получает только точные разрешённые корни этого действия;
простое добавление realm не разрешает менять все afterlife roots.

## Обязательные примеры

1. Неизвестная личность: косвенный trace без спойлера и без создания всех акторов.
2. Guardian q4 и личная сцена: разные source, proofs и награды.
3. Личная сцена: start→pause→resume→completion→реальное применение искусства.
4. Rejected completion/recovery/replay: ни половинной, ни двойной выдачи.
5. Первая встреча с Сарефом в обоих порядках раскрытия.
6. Visitor round-trip и stale trade refusal без reset/клятвы/дубликатов акторов.
7. Освобождение убежища: отдельные последствия для населения, сердца и Крыльев.
8. Guardian POV: два места, осмотр, разговор, возвращение к собеседнику с его
   памятью разговора; историческая способность и fixed событие.
9. A→pause→B→reload→A: сохранённые открытия, локальные акторы и одна active сцена.
10. Memory normal/repair: попытка изменить present actor/profile/scheduler отклонена;
    pending backlog сохранён, stale target отказан, transcript имеет scene owner.
