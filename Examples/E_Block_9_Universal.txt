## Пример 1: Иерархический Доступ к Рангам

### Сценарий: Эксперт создает мебель уровня Практика

**Фэнтези сеттинг**:
```
Игрок: Плотник 5 уровня (Эксперт) хочет сделать обычный стол (Практик, уровень 3)
Проверка: 5 >= 3 → Доступно
Бонус мастера: Автоуспех + качество улучшено с "Обычного" до "Шедевра"
```

**Киберпанк сеттинг**:
```
Игрок: Дизайнер 5 уровня (Эксперт) хочет создать умное кресло (Практик, уровень 3)  
Проверка: 5 >= 3 → Доступно
Бонус мастера: Автоуспех + дополнительные умные функции
```

**Космоопера сеттинг**:
```
Игрок: Инженер 5 уровня (Эксперт) хочет создать гравитационную кровать (Практик, уровень 3)
Проверка: 5 >= 3 → Доступно  
Бонус мастера: Автоуспех + повышенная энергоэффективность
```

## Универсальные Навыки Крафта (Полный Список)

### 1. Technical Manufacturing (Техническое Производство)
**Охватывает**: Инструменты, машины, оружие, броня, электроника, транспорт, роботы

### 2. Biochemical Processing (Биохимическая Обработка)  
**Охватывает**: Еда, лекарства, яды, парфюм, краски, топливо, алхимия

### 3. Material Crafting (Материальная Обработка)
**Охватывает**: Одежда, мебель, украшения, книги, упаковка, текстиль

### 4. Artistic Creation (Художественное Творчество)
**Охватывает**: Живопись, музыка, литература, скульптура, декор, развлечения

### 5. Structural Engineering (Инженерное Строительство)
**Охватывает**: Здания, мосты, дороги, инфраструктура, укрепления

### 6. Information Systems (Информационные Системы)
**Охватывает**: ПО, базы данных, ИИ, сети, медиа-контент, виртуальная реальность

## Ключевые Принципы Универсальности

1. **Функция важнее формы**: "Processing tool" подходит для кухонного блендера, алхимического котла, и квантового синтезатора
2. **Абстрактные категории**: "Biochemical Processing" охватывает готовку, алхимию, фармакологию и нанохимию
3. **Полный спектр жизни**: От еды до искусства, от мебели до космических кораблей
4. **Единые правила**: Математика остается одинаковой для создания хлеба или звездолета

Теперь система крафта действительно универсальна - можно создать ВСЁ, что существует в любом игровом мире!
