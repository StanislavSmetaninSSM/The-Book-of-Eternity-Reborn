GM worker Guardian/Abode content example.

This example is a worker-proposal-v1 contract example for a hidden/background
proposal-only worker. The main GM remains responsible for the player turn,
final narration, validation, and canonical state writes.

Runtime entrypoint:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File "BookOfEternityClient/Launcher/gm_worker_cli_runner.ps1" -AgentCommand "codex exec -m gpt-5.5 -c model_reasoning_effort="high" --dangerously-bypass-approvals-and-sandbox --skip-git-repo-check -" -TimeoutSeconds 120
```

The worker receives:

- `BOE_WORKER_TASK_PATH`
- `BOE_WORKER_PROPOSAL_PATH`
- `BOE_WORKER_SESSION_PATH`

Rejected patterns:

- a `guardian-abode-content` task without `afterlifeContract`;
- a proposal that uses `UpdateNPCs`, `NPCRelationshipChanges`,
  `factionDataChanges`, `worldMapUpdates`, or other Mortal World substitutes;
- visible summaries that reveal GM-only Guardian dossier facts;
- target surfaces outside the `afterlifeContract.allowedAfterlifeSurfaces` list.
