# High Stakes Mortality

## Description
This global system mod makes mortal worlds harsher and more dangerous without rewriting the soul system.

## Rules
- Mortal injuries should feel heavier and have longer consequences.
- Safe resolutions should exist, but they should be rarer than in the base tone.
- Social failure, panic, exhaustion, and reputation collapse should matter more.
- Keep the core formulas intact unless the mod text explicitly redefines them.

## Scope
This mod is global. It affects all future turns while the mod is enabled.
